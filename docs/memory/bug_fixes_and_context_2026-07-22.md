## 口径边界

- 当前历史结果只能说明已有真实样本表现，不能承诺未来高胜率或实盘收益。样本不足、区间过宽或扣成本收益不为正时，不应把策略标成可实盘。
- 实验策略是第五个独立观察策略，不替换、不合并也不暗改原四策略；达到统计门槛后仍需人工复核不同市场阶段，不能自动转正。
- 个股页的规则评分、相似形态上涨占比、技术信号成功率、决策模型成功率、策略胜率和个人实盘胜率是不同对象，必须分别展示和解释。
