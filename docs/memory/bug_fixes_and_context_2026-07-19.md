# 2026-07-19 周期、四策略回测与本地调度修复

## 已完成

- 新增统一周期模块，个股分析和回测共用 `1周、1月、3月、6月、1年、2年、5年` 的自然时间定义、日期切片和覆盖检查；2 年、5 年按自然年回溯，不再使用固定行数冒充对应周期。
- 个股分析新增 5 年走势图选项，并显示实际数据起止日期和交易日数量。A 股技术指标、交易信号、决策仪表盘和量化快照继续固定使用 `1y` 前复权日 K，所选长周期只控制走势图和原始数据范围。
- A 股多源日 K 获取同时检查最新交易日和请求周期覆盖；某个真实源只有短历史时会继续尝试其他真实源。所有真实源都不足时保留最佳真实部分并标记覆盖不足，不生成模拟数据。
- 回测页主入口改为短线、短线经典版、激进突破型、多因子稳健型四策略真实验证：读取已经保存的真实 T+1 推荐计划，再用后续真实日 K 收盘价计算 1 日、5 日、20 日胜率和平均收益。原单股通用技术信号验证保留为独立“单股信号诊断”页签。
- 四策略验证不会拿今天的候选池、财务、资金或消息数据伪装成历史时点重新选股，也不改变现有策略股票池、过滤、评分、排序或推荐数量。页面同时显示请求范围和真实计划实际覆盖范围，缺少多年计划时明确提示不足。
- 修复 `start.bat` 中调度器日志重定向符被当作 Python 命令行参数的问题；正确启动后 Web 和 `main.py --schedule` 由同一脚本分别拉起，已有调度器时不重复启动。
- 调度器测试默认把 `scheduler_status.json` 写入 pytest 临时目录，并增加 Windows 启动命令回归断言，避免测试假状态污染本地运行页面。

## 口径边界

- “验证全部策略”是验证四个策略真实保存的历史推荐结果，不是用当前时点数据回放过去。完整的多年历史重放需要保存每个历史时点的候选池、财务、资金、消息和风险快照；当前没有这些点时数据，因此不伪造多年策略结果。
- 回测选择 6 月、1 年、2 年、5 年表示请求范围；只有真实计划实际覆盖该范围时才算完整。计划自动积累依赖本地调度器持续存活并在 `15:45` 执行。
