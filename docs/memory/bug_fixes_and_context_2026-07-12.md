# 2026-07-12 量化展示与工程稳定性更新

## 个股只读量化快照

- 个股分析页新增“个股量化评分”，复用页面已经加载并计算指标的完整一年日 K 数据，不额外拉取行情；图表仍可按用户选择周期裁剪，量化快照不随短周期裁剪而丢失样本。A 股继续使用既有 `1y` 前复权日 K 口径，实时行情不合并进指标。
- 快照从趋势结构、动量强弱、量能配合、位置结构和风险控制五个维度给出规则分，并展示支撑位、压力位、距关键位百分比和风险提示。
- 相似形态统计按非重叠前向窗口去重，展示原始匹配数、有效样本数、历史上涨占比、Wilson 95% 区间和样本可信度。
- 页面明确标注“规则评分，尚未做收益校准”；该模块只读，不参与交易信号、推荐股票池、过滤、评分、排序或 T+1 计划生成。

## 手工成交记录编辑

- 智能推荐页的成交记录改为逐条展开，可查看、修改或删除；持有中记录可以补录卖出时间和卖出价后转为已结记录。
- 买入价和卖出价统一保留三位小数，保存修改后重新计算收益率、成功状态和成功率汇总。
- 修改只更新 `.cache/recommendation_manual_trade_records.json` 中已有记录，不重新运行推荐策略，也不写入 T+1 推荐计划历史。

## 短线经典版候选池安全

- 经典版继续保持纯技术口径，不读取热门板块或实时涨跌排行作为候选条件。
- 主板候选按沪市、深市交替取样，保留各市场原始顺序，并排除 ST、`*ST` 和退市风险名称，避免全量名称池按代码排序后前 80 只全部落在沪市。
- 该修复只恢复项目既有风险边界和“沪深主板候选池”覆盖，不增加基本面、资金、消息或形态过滤。

## 缓存、超时与辅助层加固

- 新增 `data/file_lock.py`，统一线程锁、跨进程锁、原子写入和孤儿临时文件清理。
- `JsonFileCache` 新增批量读写和过期条目压缩；策略 K 线缓存增加并发写保护、原子替换与过期文件清理。
- `data/runtime.py` 的超时调用改为共享限容执行器，超时后及时返回，同时限制后台任务堆积。
- `data_fetcher.py`、`stock_recommendation.py` 的路径、股票名、运行时和催化文本辅助函数机械迁移到独立模块；股票池、过滤、评分、排序、推荐数量和 A 股日 K 数据源优先级均未改变。
- 删除两份已无用途的临时补丁脚本，`.tmp/` 加入忽略列表，避免 Windows pytest 临时目录进入提交。
