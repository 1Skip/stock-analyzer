## 真实公司行为链路

- 新增 `data/providers/corporate_action_provider.py`，通过 AKShare 的巨潮资讯接口 `stock_dividend_cninfo` 和 `stock_allotment_cninfo` 顺序读取真实分红、送转和配股历史。
- 新增 `data/services/corporate_action_service.py`，统一标准化现金分红、送股/转增和配股事件，并为每个事件生成稳定 `action_id`。
- 只有两个公开源都返回完整成功时才缓存，默认缓存 `86400` 秒；缺失、部分成功或接口失败均明确失败关闭，不缓存不完整结果，也不补造事件。
- 统一模拟账户在每日订单成交前处理持仓对应的公司行为。现金分红增加现金；送股/转增增加数量并保持总成本不变；配股不自动认购，只写入账本并生成需要人工处理的告警。
- 公司行为写入审计流水并按 `action_id` 幂等；重复日终对账不会重复增加现金或股份。
- 组合回测改用未复权真实日 K，并复用与模拟账户相同的公司行为会计逻辑；回测输出会保留公司行为数据质量状态和源错误。
