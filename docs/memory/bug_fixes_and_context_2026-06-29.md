# 2026-06-29 短线经典版回到纯技术口径

## 短线经典版策略语义修正

- 按用户确认，短线经典版应回到最初短线的纯技术口径：只看沪深主板候选池和成交量、MACD、RSI、KDJ、BOLL，不看热门板块，也不把基本面/估值、财报盈利、资金流、消息面作为评分输入。
- `stock_recommendation.py` 中短线经典版候选池从 `_get_short_term_all_candidate_stocks(80)` 改为主板纯技术候选池，不再要求热门板块成分股匹配；候选按沪深主板交替取样并排除 ST、退市风险名称，避免代码顺序截断后只扫描沪市；诊断标记为 `pool_mode=主板纯技术池`，`hot_boards=0`。
- `_analyze_short_term()` 增加 `include_context` 参数；普通短线默认继续使用上下文辅助评分，短线经典版调用时传入 `include_context=False`，因此不会拉取或叠加基本面、财报、资金流、消息面上下文分。
- 短线经典版仍保留 3/5 技术命中门槛、Alpha 排序展示、T+1 买卖点和独立短线学习历史；仍不启用二板以上、2-8 天回调、回撤不超 50%、放量反包/涨停板四项形态硬过滤，推荐卡片的“策略命中”中也不展示“形态过滤”这一项。
- `scheduler.py` 中 T+1 预热目标调整为：只有普通短线按配置板块展开；短线经典版和激进突破型/多因子稳健型一样只生成 `全部`，避免被苹果/特斯拉专题板块误导。
- 推荐页和 README 已同步文案，明确经典版是原始纯技术短线，不检查热门板块、基本面、财报、资金流、消息面。
